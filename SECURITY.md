# Güvenlik / Security

Bir güvenlik açığı bulduysanız lütfen herkese açık bir issue açmayın. Depodaki **Security → Report a vulnerability** düğmesiyle gizli olarak bildirin.

If you find a security vulnerability, please do not open a public issue. Report it privately with **Security → Report a vulnerability** on this repository.

Desteklenen sürüm: yalnızca `main` dalındaki en son sürüm. / Supported version: the latest release on `main` only.
